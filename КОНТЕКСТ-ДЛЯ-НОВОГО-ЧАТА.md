## Что мы делаем

Конвертируем React/Lovable лендинг (https://scale.gorkybusiness.school) в чистый HTML/CSS/JS для Tilda CMS. Продакшн-страница: https://school-gorki.ru/scale

Лендинг — это 3-дневный выездной интенсив "Масштабирование бизнеса в новых реалиях" для предпринимателей с оборотом от 100 млн. Школа бизнеса Горки, Доброград, 18-20 сентября 2026.

## Архитектура

Страница разбита на **8 T123 HTML-блоков** в Tilda + **1 Zero Block** (дерево методологии).

Файлы лежат в папке `tilda-blocks/`:

| Файл | Содержимое |
|------|-----------|
| `block-01-css.html` | Все CSS-стили. Tailwind грузится через `@import url(...)` внутри `<style>` (Tilda вырезает `<link>` теги!) |
| `block-02-content.html` | Навбар, герой, "что происходит сегодня", кризисы, о школе, Анти-МВА |
| `block-03-content.html` | Выпускники + сообщество + целевая аудитория + демография |
| `block-04a-content.html` | Попечительский совет + программа (до дерева) |
| **Zero Block** | Дерево методологии — импортирован из gorkybusiness.school/scale/, НЕ наш файл |
| `block-04b-content.html` | Референс-визит + локация Доброград + преподаватели + миссия |
| `block-05-content.html` | Карусель отзывов |
| `block-06-content.html` | FAQ (8 вопросов) + inline Marquiz + подвал |
| `block-07-scripts.html` | Весь JavaScript: Marquiz, меню, карусель, FAQ, exit-intent, scroll fixes |

## Критически важные технические моменты

### 1. Tailwind CSS
Грузится ТОЛЬКО через `@import url('https://scale.gorkybusiness.school/assets/index-e29d3z3F.css')` в первой строке `<style>` в block-01. Tilda вырезает `<link>` теги из T123 блоков — `@import` единственный работающий способ. **Без этого CSS все адаптивные классы мёртвые и страница сломана.**

### 2. Marquiz (квиз/форма)
- ID: `68c3bfd9cb49020019f482c8` (Васильева)
- Все CTA кнопки открывают через `Marquiz.showModal(id)` — НЕ через `window.location.hash` (hash вызывает скролл)
- Inline Marquiz встроен в block-06
- Init скрипт в block-07

### 3. Мобильный скролл
Была хроническая проблема — скролл на мобильных не работал. Причины и фиксы:
- React ставил `transform: translateY()` на элементы → JS убирает (кроме Marquiz, карусели, nav, Tilda-обёрток)
- `touch-action: pan-y pan-x !important` на Tilda-обёртках (`.t-rec`, `.t123`, `.t-body`, `#allrecords`)
- `touch-action: pan-y !important` на `.t396__artboard` (Zero Block)
- `overflow-y: auto !important` на html/body
- Убран `e.stopPropagation()` с CTA кнопок
- Мобильное меню НЕ ставит `overflow: hidden` на body

### 4. Tilda-специфика
- T123 блоки ≤ 40KB
- Каждый блок — независимый HTML-контекст
- Tilda переопределяет цвета ссылок → `color: inherit !important`
- Шрифты Tilda Sans грузятся с CDN Tilda
- Между блоками `margin-top: -1px` чтобы не было щелей
- `opacity: 1 !important` на всех элементах (React ставил opacity: 0 для анимаций)

### 5. Zero Block (дерево)
Импортирован из другого проекта Tilda (gorkybusiness.school/scale/). Стоит между block-04a и block-04b. Уже адаптивный. Не трогать.

## Что работает в JS (block-07)

1. **Marquiz popup** — все CTA кнопки → `showModal()`
2. **Мобильный скролл фикс** — принудительный touch-action и overflow при DOMContentLoaded
3. **React transform fix** — убирает translateX/Y (selective, не ломает Tilda)
4. **Бургер-меню** — position:fixed, навигация + CTA
5. **Speaker tooltips** — hover на десктопе, тап на мобильном (4 сек)
6. **FAQ аккордеон** — single-open, анимация max-height
7. **Карусель отзывов** — prev/next, dots, авто-прокрутка 8 сек
8. **Navbar scroll** — фон + blur при скролле > 50px
9. **Progress bars** — JS читает % текст → ставит width
10. **Exit-intent popup** — desktop: mouseout clientY<0; mobile: 60% scroll или 20 сек
11. **Logo click** → smooth scroll to top

## Дизайн-система

- Фон: `hsl(160, 55%, 5%)` (тёмный teal)
- Акцент: `hsl(160, 60%, 42%)` (зелёный)
- Светлые секции: `hsl(155, 35%, 94%)`
- Шрифт: Tilda Sans (400-900)
- Кнопки: rounded-full, зелёный фон
- Цитаты: border-left 4px зелёный

## Как деплоить

1. Открыть Tilda → school-gorki.ru/scale
2. Каждый block-XX → отдельный T123 блок (Другое → HTML-код)
3. Порядок: 01 → 02 → 03 → 04a → [Zero Block] → 04b → 05 → 06 → 07
4. Скопировать содержимое файла целиком в T123 блок
