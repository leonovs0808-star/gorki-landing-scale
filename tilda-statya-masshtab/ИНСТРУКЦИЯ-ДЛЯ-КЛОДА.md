## КРИТИЧЕСКИ ВАЖНО: порядок действий при любой правке

Когда пользователь просит изменить что-то в статье, ВСЕГДА делай ВСЁ по порядку:

### Шаг 1. Переключись на ветку main
```
git checkout main
git pull origin main
```

### Шаг 2. Найди нужный блок и внеси правку
Определи, в каком файле находится то, что нужно изменить:
- Введение, сайдбар → `01-vvedenie.html`
- Масштабирование → `02-masshtabirovanie.html`
- Почему сейчас → `03-pochemu-seichas.html`
- Ошибки → `04-oshibki.html`
- Точка потенциала → `05-tochka-potentsiala.html`
- Контекст → `06-kontekst.html`
- Личность → `07-lichnost.html`
- Дело → `08-delo.html`
- Итог → `09-itog.html`

Внеси правку в ОТДЕЛЬНЫЙ БЛОК (НЕ в statya.html напрямую!).

### Шаг 3. Пересобери statya.html
```
cd tilda-statya-masshtab && bash build.sh
```
Это автоматически соберёт новый `statya.html` из всех отдельных блоков.

### Шаг 4. Закоммить и запушь ОБА файла
```
git add tilda-statya-masshtab/ИЗМЕНЁННЫЙ-БЛОК.html tilda-statya-masshtab/statya.html
git commit -m "описание правки"
git push -u origin main
```

### Шаг 5. Скажи пользователю обновить страницу
Скажи: «Готово! Обнови страницу через Ctrl+Shift+R (30-60 сек на деплой GitHub Pages)»

## НЕ ЗАБЫВАЙ

1. **НИКОГДА не правь statya.html напрямую** — только через отдельные блоки + build.sh
2. **ВСЕГДА пересобирай statya.html** после правки любого блока
3. **ВСЕГДА пушь на main** — GitHub Pages работает с main
4. **ВСЕГДА коммить и отдельный блок, и statya.html** — чтобы и превью, и код для Tilda были синхронизированы
5. Каждый блок — самостоятельный HTML для Tilda T123 (лимит 40KB)
6. CSS и JS инлайн в каждом блоке (Tilda не поддерживает внешние файлы в T123)

## Ограничения Tilda T123

- Максимум 40KB на блок
- Каждый блок — независимый HTML-контекст
- Tilda вырезает `<link>` теги — внешний CSS только через `@import url(...)` внутри `<style>`
- Tilda переопределяет цвета ссылок — нужны `!important`
- Шрифты: Inter загружается через Google Fonts в блоке 01

## Как пользователь переносит код на Tilda

1. Открывает файл блока на GitHub (например `06-kontekst.html`)
2. Нажимает Raw → копирует весь текст
3. В Tilda: Другое → T123 HTML-код → вставляет
4. Порядок блоков: 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09
